# Поднебесная — сайт-визитка

Одностраничный сайт-визитка о Китае: баннер, блок «О сайте», лента новостей
со скроллингом, информация об авторе и контакты. Всё, кроме форума,
размещено на главной странице. Версия только для десктопа.

## Состав

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная страница со всеми секциями |
| `styles.css` | Все стили, палитра и типографика |
| `main.js` | Анимации появления, активное меню, форма, кнопка «наверх» |
| `forum.html` | Заготовка страницы форума с планом подключения |

Внешних зависимостей и сборки нет. Шрифты подключаются с Google Fonts,
при отсутствии сети используется системный fallback.

## Запуск

Открыть `index.html` двойным щелчком либо поднять локальный сервер
(рекомендуется — так корректно работают относительные пути):

```bash
python -m http.server 8000
```

После этого сайт доступен по адресу `http://localhost:8000`.

## Структура главной

1. **Баннер** — SVG-пейзаж с горами, солнцем и туманом, заголовок, кнопки
   и три показателя.
2. **О сайте** (`#about`) — три карточки: язык, культура, практика.
3. **Лента новостей** (`#news`) — блок фиксированной высоты с собственной
   прокруткой; слева «прилипающий» заголовок раздела.
4. **Об авторе** (`#author`) — портрет-плейсхолдер, биография, факты, теги.
5. **Контакты** (`#contacts`) — карточки контактов и форма, которая
   формирует письмо через `mailto:`.
6. **Подвал** — навигация и кнопка «наверх».

## Что заменить на своё

- **Тексты и имя** — `index.html`, блоки `#about`, `#author`, `#contacts`,
  а также подвал.
- **Контакты** — e-mail, Telegram, WeChat в `#contacts` и в `main.js`
  (адрес в `mailto:`).
- **Новости** — карточки `<article class="news-card">` внутри `.news-feed`.
  Скопируйте блок и поменяйте дату (`datetime` и текст), тег, заголовок
  и описание.
- **Фото автора** — в `styles.css` у класса `.author-photo` раскомментируйте
  и настройте:

  ```css
  background-image: url("img/author.jpg");
  background-size: cover;
  background-position: center;
  ```

  После этого можно скрыть `.author-glyph` и `.author-photo-hint`.
- **Баннер** — замените инлайн-SVG `.hero-art` на своё изображение:
  `<img src="img/banner.jpg" alt="">` внутри `.hero-media` либо задайте
  `background-image` для `.hero`.
- **Палитра** — переменные `--gold`, `--bg`, `--text` и другие в начале
  `styles.css`.

## Лента новостей

Прокрутка реализована на CSS: `.news-feed` имеет `max-height: 640px`
и `overflow-y: auto`, плюс кастомный скроллбар. Чтобы изменить высоту,
поправьте `max-height` в `styles.css`. Количество новостей не ограничено —
лента растёт вниз внутри блока.

## Подключение форума

Сайт статический, поэтому форум ставится отдельным движком:

1. **Движок** — `Flarum` или `NodeBB` для небольшого сообщества,
   `Discourse` для активного, `phpBB` — самый простой вариант на PHP-хостинге.
2. **Размещение** — поддомен `forum.example.ru` или папка `/forum`.
   Нужны база данных и SSL.
3. **Связка** — замените ссылки `forum.html` в меню и подвале
   (`index.html`, `forum.html`) на адрес форума. Страницу `forum.html`
   можно оставить как промежуточную или удалить.

Стили шапки и подвала из `styles.css` переносятся в тему движка, чтобы
оформление совпадало.

## Технические заметки

- Ширина контента фиксирована (`1180px`), у `body` задан `min-width: 1080px` —
  мобильной вёрстки нет по требованию.
- Плавная прокрутка и отступ под фиксированную шапку — через
  `scroll-behavior` и `scroll-padding-top`.
- При `prefers-reduced-motion: reduce` анимации отключаются.
- Форма не отправляет данные на сервер: она валидирует поля и открывает
  почтовый клиент. Для реальной отправки подключите обработчик
  (Formspree, собственный backend и т. п.) в `main.js`.
